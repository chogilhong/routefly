# routefly

경로를 3D 지형 위에서 따라가며 보여 주는 웹입니다. 코스를 고르면 출발점으로 날아가 경로를 그리면서
카메라가 따라가고, 진행 거리 · 고도 · 고도 그래프 · 지점 이름표가 같이 움직입니다.

코스 자료는 **routefly-batch** 가 GPX 를 읽어 MariaDB 에 넣습니다. 이 웹은 그 표를 **읽기만** 합니다.
구성은 investing 과 같습니다(Tomcat 11 · Jakarta Servlet 6.1 WAR, JDBC 직접, Gson, Log4j2, 설정 파일은 저장소 밖).

## 처음 셋업

1. 설정 파일을 저장소 밖에 만듭니다: `src/main/resources/config.properties.example` →
   `C:\GH\config\routefly\config.properties` 로 복사하고 값을 채웁니다.
   - `db.url` / `db.user` / `db.password` - routefly-batch 와 같은 DB. 웹은 SELECT 권한만 있으면 됩니다.
     ```sql
     GRANT SELECT ON routefly.* TO '웹계정'@'localhost';
     ```
   - `db.pool.maxActive` / `db.pool.maxIdle` - DB 연결 풀 크기(기본 10 / 5). 비우면 기본값.
   - `map.vworld.key` - 배경 위성사진(국토교통부 V-World, 무료 발급, 서비스 주소 등록). 비우면 지형 음영만 나옵니다.
   - `map.dem.url` - 3D 지형 타일. 비우면 AWS Terrain Tiles(routefly-batch 의 기본 `dem.url` 과 같음).
2. 다른 위치에 두려면 톰캣 실행 인자에 `-Droutefly.config=<경로>` 를 넣습니다.
3. 이클립스: File → Import → Maven → Existing Maven Projects → 톰캣 11 서버에 추가.
   주소는 `http://localhost:8080/routefly/`.

## 구조

| 자리 | 내용 |
|---|---|
| `RouteflyConfig` | 설정 파일 읽기(investing 의 InvestingConfig 와 같은 방식) |
| `Db` | 요청마다 JDBC 연결 |
| `CourseQueries` | 코스 표 읽기 + 요청 값 검사(코스 ID · bbox · kind) |
| `CoursesServlet` | `GET /api/courses[?q=이름][&bbox=minLon,minLat,maxLon,maxLat][&kind=hike]` - 코스 목록(요약, 최대 300개 + `truncated`) |
| `CourseServlet` | `GET /api/course?id=<코스ID>` - 요약 + 경로 점 `[경도,위도,고도,누적거리]` + 이름표 |
| `TrailsServlet` | `GET /api/trails?bbox=` - 범위(0.2° 안) 코스 선을 솎아서(약 30m) - 산행 화면의 "가장 가까운 등산로" |
| `ShareServlet` | `GET /s/<코스ID>[?to=hike]` - 공유 링크. 미리 보기 카드(Open Graph: 이름 · 거리 · 오르막, `img/og.png`) 뒤 화면으로 넘어감 |
| `sw.js`, `manifest.json` | 홈 화면에 추가(PWA) · 오프라인(화면 파일 · API 는 인터넷 먼저, 지도 타일은 받아 둔 것 먼저) |
| `MapConfigServlet` | `GET /api/map-config` - V-World 키 · 지형 타일 주소 |
| `webapp/index.html`, `js/app.js` | 지도 화면(MapLibre) |
| `webapp/hike.html`, `js/hike.js` | 핸드폰 산행 화면(GPS) |
| `webapp/about.html` | 안내 - 안전 · 위치/개인정보 · 자료 출처(두 화면 출처 표시와 산행 화면 ⓘ 에서 연결) |
| `js/course-kit.js`, `css/course-kit.css` | 두 화면 공통 - 코스 위치 계산 · GPS 맞추기 · 고도 그래프 · 작은 평면 지도 |
| `webapp/vendor/maplibre-gl-5.24.0` | MapLibre GL JS(BSD-3, LICENSE.txt 동봉) - CDN 없이 이 앱이 내려줍니다 |

코스 자료 응답은 5분 캐시(`Cache-Control: public, max-age=300`)입니다 - 배치가 1시간마다 바꾸는 공개 자료라서입니다.
로그인은 없습니다(investing 과 달리 개인 자료가 없는 공개 화면). 쓰기 API 가 생기면 그때 붙입니다.

## 화면

- **지도**: 3D 지형(Terrarium 고도 타일, 1.25배 과장) + 하늘 · 안개. 배경은 V-World 위성사진(키가 있으면)과
  지명 겹침, 없으면 지형 음영.
- **비행**: `▶ 비행` - 높이 떠올랐다가 출발점으로 내려앉은 뒤(인트로) 경로를 따라갑니다. 카메라는 58° 로 비스듬히
  내려다보며 현재 위치를 화면 가운데쯤 두고, 앞 구간 세 곳의 방향 평균을 시간 기준으로 부드럽게 따라 돌아 지그재그 길에서도
  흔들리지 않습니다. 카메라 중심 높이는 매 프레임 그 자리 지형 높이로 맞춥니다(안 그러면 산 위에서 현재 위치가 화면 밖으로 밀림).
  카메라와 현재 위치 사이에 능선이 끼면 지형 높이를 재서 카메라를 들어 올리고(최대 42°까지), 능선이 지나가면 천천히 다시 낮춥니다.
  지나온 길은 하늘색 선, 남은 길은 흐린 가는 선, 현재 위치는 흰 테두리 동그란 배지(등산객)입니다. 비행 중에는 목록과
  V-World 지명 겹침(길 따라 비스듬히 쓰인 글자)을 숨겨 우리 이름표만 보이게 하고,
  화면 가운데에 큰 **자막**이 나옵니다 - "오색에서 출발", 지나는 지점 이름 · 거리 · 해발, 이름표가 드문 구간의 거리 이정, "대청봉 도착!".
  코스 길이에 맞춰 줌 · 앞보기 거리 · 시간(1× 기준 20~90초)을 정하므로 등산로부터 장거리 경로까지 같은 방식으로 씁니다.
  `0.25× / 0.5× / 1× / 2× / 4×` 빠르기(처음 0.25×, 누를 때마다 다음), `전체` 로 코스 전체 보기. 지도를 직접 끌거나 돌리면 멈춥니다. 스페이스 키로 멈춤 / 이어서.
- **코스 고르기**: 검색어가 없으면 **지금 지도 범위 안의 코스**를 목록으로 보여 주고(지도를 움직이면 다시 받음),
  검색창에 이름(예: "설악산", "공룡")을 적으면 전국에서 찾습니다. 지도에는 목록 코스의 출발점이 점으로 찍히고,
  가까운 점은 큰 원으로 묶입니다(누르면 확대). 점을 누르면 그 코스를 엽니다. 300개가 넘으면 "확대하거나 검색하세요" 를 띄웁니다.
- **고도 그래프**: 지나온 구간을 칠하고 지금 위치 점이 따라갑니다. 지점 이름(빨간 점 위 비스듬한 글씨)과 km 눈금이 있고,
  그래프를 누르면 그 거리로 옮깁니다. 오른쪽 위에는 진행 거리 · 고도 · **경사**, 그 아래 **작은 평면 지도**(북쪽이 위,
  km 번호 · 지점 · 지금 위치)가 있습니다.
- **📱 산행**: 지금 코스를 핸드폰 산행 화면(`hike.html`)으로 엽니다. **공유**: 코스 카드가 뜨는 링크(`/s/<코스ID>`).
- **등산 · 걷기 · 자전거**: 목록 위 단추로 나눠 봅니다(routefly-batch 의 `walk/` · `bike/` 폴더 GPX). 목록에 표준 소요 시간.
- **이름표**: 아이콘(봉우리 · 절 · 대피소 · 고개 · 폭포 · 안내소 · 주차장 …, 이름 끝말로 고름) + 흰 글씨. GPX 의 `<wpt>`(산림청 코스는 routefly-batch 가 OpenStreetMap 지명으로 붙인 들머리 · 대피소 · 정상).
  앞쪽 지점도 미리 보입니다. 출발 · 도착 자리에 이름표가 있으면 "출발" · "도착" 대신 그 이름을 씁니다
  (예: 오색(남설악탐방지원센터) - 출발).
- 주소 `#c=<코스ID>` 로 그 코스를 바로 엽니다. 휴대폰 화면에서는 비행을 시작하면 목록을 접습니다.
- 출처 표시(등산로 산림청 · 지형 · 위성사진 · 지명 이용 조건 + 안내 링크)는 오른쪽 위에 있습니다 - 가리거나 지우지 마세요.
  지명은 OpenStreetMap(ODbL)이라 "© OpenStreetMap contributors" 를 늘 같이 표시합니다.

## 산행 화면 (`hike.html`, 핸드폰)

걸으면서 GPS 로 내 위치를 코스에 맞춰 보여 주는 화면입니다. 주소 `hike.html#c=<코스ID>`, 코스가 없으면 검색 · "내 주변 코스"(5km 안) ·
등산 / 걷기 / 자전거 구분 · "내 기록".

| 자리 | 내용 |
|---|---|
| ③ 지도(위) | 북쪽이 위. 코스 흰 선 · 지나온 길 하늘색 · km 번호 · 지점 아이콘 · 갈림길(작은 점) · 주변 다른 길(노란 점선) · 내 위치(파란 점 + 가는 방향). 손으로 움직이면 따라가기가 꺼지고 ⌖ 로 다시 |
| ② 산행 기록(가운데) | 다음 지점(이름 · 남은 거리 · 고도차), 진행 거리 · 남은 거리 · 해발 · 경사 · 속도 · 경과 시간, 남은 오르막 · 예상 도착 · 일몰 |
| ① 고도 그래프(아래) | 지점 이름 · km 눈금 · 지금 위치 |

- **🧭 나침반**(지도 왼쪽 위): 누르면 켜짐(아이폰은 권한 물음) → 한 번 더 누르면 내가 보는 방향이 위로 오게 지도를 돌림 → 다시 누르면 북쪽 위.
  멈춰 있을 때 내 위치의 방향 표시도 나침반을 씁니다.
- **SOS**(위 막대): 119 전화 · 119 문자 신고(위치 · 코스 · 해발을 넣은 글), 내 **국가지점번호**(UTM-K 10m 격자 - 산 위치표지판과 같은 체계) ·
  위경도 · 해발, 위치 복사. 산행 중이 아니어도 현재 위치를 한 번 받아 보여 줍니다.
  **위치 사진 보내기**: 내 위치를 가운데 둔 지도(코스 · 주변 길 · 이름표 · 오차 원 · 축척)에 문자와 같은 위치 글을 붙인 JPG 한 장을 만들어
  공유 창(Web Share)으로 넘깁니다 → 메시지 → 받는 사람 119. 공유 창을 못 쓰는 브라우저는 사진을 저장합니다.
  (사진을 만드는 사이 브라우저가 공유를 막으면 버튼이 "📤 한 번 더 누르세요" 로 바뀝니다.) 사진은 기기 안에서만 만들어집니다.
- **음성 안내**(지도 왼쪽 🔊, 기본 켜짐 · 이 기기에 기억): 브라우저 내장 읽어 주기(Web Speech API, 한국어). 시작 · 갈림길 80m 앞(방향) ·
  지점을 지날 때(이름 · 해발) · 1km 마다(자전거 5km - 남은 거리 · 남은 오르막) · 코스 이탈(가장 가까운 길 방향 · 거리, 2분마다) · 복귀 ·
  일몰 경고 · 도착. 시작 버튼을 누를 때 처음 말해야 아이폰도 소리를 냅니다. 화면이 켜져 있을 때 확실히 나옵니다.
- **가장 가까운 등산로 안내**: 코스에서 50m 넘게 벗어나면 지금 코스와 주변 길(`/api/trails`) 가운데 가장 가까운 자리까지 거리 · 방향 · 화살표
  (나침반이 있으면 핸드폰 위쪽 기준 - 화살표 쪽으로 몸을 돌려 걸으면 됨), 지도에 빨간 점선.
- **갈림길 미리 알림**: 갈림길 80m 앞에서 진동 + "50m 앞 갈림길 · 오른쪽 길"(코스가 꺾는 쪽).
- **일몰 경고**: 예상 도착이 해 지기 30분 전보다 늦으면 예상 도착 칸이 빨개지고 한 번 알림 + 진동.
- **기록**: 걸은 자리(8m · 1분마다)를 이 기기에 남기고, "산행 끝내기" 하면 요약(걸은 거리 · 시간)과 **GPX 저장**. "내 기록"(최근 20개)에서 다시 받기 · 지우기.
- **📥 저장(오프라인)**: 코스 · 주변 길 자료와 코스 둘레 약 500m 의 지도 그림(z10~16, 3,000장 안)을 핸드폰에 받아 둡니다 -
  산속에서 통신이 끊겨도 보임. **홈 화면에 추가**하면 앱처럼 열립니다(PWA).
- **공유**: `/s/<코스ID>` 링크 - 카카오톡 등에서 코스 카드(이름 · 거리 · 오르막)가 뜹니다.
- **종류별 예상 시간**: 등산 · 걷기 4km/h + 오르막 600m/h, 자전거 15km/h.
- **코스에 맞추기**: GPS 위치를 코스 선에 붙여 진행 거리를 셉니다(지난 자리 앞뒤 800m 를 먼저 봐서 오가는 길에서 엉뚱한 쪽에 붙지 않음).
  정확도가 100m 보다 나쁜 위치는 버립니다. **50m 넘게 벗어나면** 빨간 알림과 코스 쪽 방향("코스는 북동쪽"), 끝점 30m 안이면 도착 알림 + 진동.
- **예상 도착**: 표준 산행 시간(평지 4km/h + 오르막 600m/h)에, 10분 넘게 걸은 뒤에는 지금까지의 빠르기 비율(0.6~2.5배)을 곱합니다.
- **화면 켜 두기**: Wake Lock(지원 브라우저). 새로 고침해도 시작 시각 · 진행 거리는 이 기기에 남아 "이어서 산행"(하루 지나면 버림).
- **모의 산행**: GPS 없이 코스를 따라 걷는 흉내(3.5km/h, 40배속) - 집에서 화면 시험용.
- **안전 · 위치 안내**: 실제 "산행 시작" 을 처음 누르면 안내 창(참고용 정보 · 통제 구간 · GPS 오차 · 119 · 위치는 기기에서만)을
  띄우고 "확인했습니다" 를 체크해야 시작합니다(이 기기에 한 번 기억, 내용을 바꾸면 hike.js 의 `SAFETY_KEY` 를 v2 로).
  자세한 내용은 `about.html`. **공개 전에 about.html 의 "문의"(id="contact")에 운영자 연락처를 넣으세요.**
- ⚠ **GPS 는 https 주소에서만** 켜집니다(브라우저 규칙). 핸드폰으로 실제 산행에 쓰려면 이 웹을 https 도메인으로 올려야 합니다.
  http 주소에서는 "모의 산행" 만 됩니다.
- ⚠ 지도 타일은 인터넷으로 받습니다 - 산속 통신이 안 되는 곳에서는 이미 본 곳만 보이고, 위치 · 기록 · 그래프는 계속 됩니다.

## 시험

```
powershell -NoProfile -ExecutionPolicy Bypass -File .claude\run-tests.ps1
```

DB 없이 돕니다(설정 경로, 코스 ID · bbox · kind 검사, 응답 모양). 화면은 주소에 `?debug` 를 붙이면
`window.routeflyDebug` 로 지도 상태를 볼 수 있습니다(브라우저 자동 시험용).

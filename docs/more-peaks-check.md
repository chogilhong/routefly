# 이름난 산 6곳 정상 자리 · 높이 · 코스 수 (PC 2026-11-27)

웹 메모(v471) "이름난 산 자료" 3번. data/mountains-more.json peaks 에 넣을 값의 근거. PC 가 읽은 곳과 값만 적음(지어낸 값 없음).

읽은 곳
- OSM: tools\map\work\summits.geojson (칸 name · ele · src) - PC target\more_peaks.py 로 읽음.
- 산림청 코스 끝점: 운영 /routefly/api/courses?q=<산> 에서 "… → <정상>" 꼴 산림청(frst) 코스의 end_lat · end_lon (산림청 등산로 자료의 정상점).
- 백과: 한국민족문화대백과사전 본문(PC _dl\ency).
- 코스 수: 운영 /routefly/api/courses?kind=hike&bbox=(정상 ±0.03° 경도 · ±0.025° 위도), 잘림(truncated) 없음, 들머리나 끝이 정상에서 2,000m 안인 코스 - MountainServlet NEAR_M 과 같은 기준(다만 목록 API 는 Steep.dropFarMiss 를 거친 뒤라 서블릿 값과 조금 다를 수 있음).
- 정상석 사진(stone) · 국토지리정보원 고시(ngii) 원문은 PC 가 확인하지 못함 - 아래 높이는 백과 · OSM 값. peak-elev.json 에 넣으려면 stone/ngii 근거가 따로 필요.

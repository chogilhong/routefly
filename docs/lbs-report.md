# 위치기반서비스사업 신고 (소상공인 사후 신고 - 마감 2026-11-19)

2026-10-21 홍TV님 "위치기반서비스사업 신고부터 하자". 산악회 방을 2026-10-20 에 켰으므로 위치정보법 제9조의2(소상공인 · 1인 창조기업 특례)에 따라
사업을 시작한 날부터 1개월 안(2026-11-19)에 신고합니다. 이 문서는 서류에 적을 "서비스 사실"을 코드와 맞춰 모은 것입니다.
상호 · 대표자 · 주소 · 전화 · 사업자번호 같은 개인 · 사업 정보는 여기에 적지 않습니다(홍TV님이 신고 화면 · 서류에 직접).

## 1. 순서

1. 소상공인확인서 유효기간 확인(sminfo.mss.go.kr - 홍TV님 이미 있음, 2026-10-20). 지났으면 다시 발급(약 1주).
2. 위치정보지원센터(www.lbsc.kr) → "소상공인등의 위치기반서비스 사업신고" 화면에서 양식 "[공통] 소상공인등의 위치기반서비스 사업내용 설명자료" 받기.
3. 아래 3번 내용으로 설명자료 채우기(빈칸은 홍TV님).
4. 전자민원(www.emsit.go.kr) → 위치기반서비스사업 신고(소상공인등) → 설명자료 + 소상공인확인서 붙여 제출. 공동인증서 또는 간편인증 필요. 수수료 없음.
5. 보완 요청은 신청서에 적은 전화로 옴. 수리까지 최대 2주 안팎.
6. 수리되면 신고번호를 개인정보처리방침(privacy.html#party)에 적음(웹 Claude 에게 번호만 - 번호는 공개 정보).

모르면 LBS지원센터 02-550-9521 · 9522, 위치정보 맞춤형 컨설팅 02-3786-0692.

## 2. 신고 전에 센터에 물어볼 것

- 산악회 방에서 회원 위치를 같은 방 사람(인솔자 · 운전자 · 회원)에게 보여 주는 것이 "개인위치정보의 제3자 제공"(제19조 - 제공할 때마다 통보)에 해당하는지,
  해당하면 통보를 어떻게 해야 하는지(지금은 참가 때 한 번 동의 + 화면에 늘 "누가 보는지" 표시).
- 위치를 서버 메모리에 사람마다 마지막 하나만 두고(파일 · DB 에 안 씀) 방이 끝나면 지우는 방식에서, 보호조치 증명으로 무엇을 내면 되는지.
- 따라가기(hike.html)는 위치를 폰 안에서만 쓰고 서버로 보내지 않음 - 신고 대상에서 빠지는지(설명자료에 함께 적을지).
- 익명 자취(별명 · 방 · 시각 없음, 처음 · 끝 500m 뺌)를 DB 에 두는 것이 "개인위치정보"가 아닌 위치정보로 보아도 되는지, 설명자료에 어떻게 적을지.
- "내 주변 코스" 검색이 지도 범위(약 1km 칸)를 서버로 보내는 것도 적어야 하는지(서버에 남기지 않음 - 접속 기록에도 ? 뒤를 안 남김).

## 3. 설명자료에 적을 내용(서비스 사실)

### 서비스 개요
- 서비스 이름: routefly 산악회 방 (https://routefly.kr/routefly/party.html, 안드로이드 앱 routefly - 원스토어 출시 준비 중)
- 시작일: 2026-10-20
- 이용자: 안내 산악회 인솔자 · 예약 회원 · 버스 운전자. 회원 가입 · 로그인 없음, 무료, 광고 없음.
- 하는 일: 인솔자가 산행 방을 만들고 회원이 방 코드로 참가 → 같은 방 사람들이 서로의 위치 · SOS 를 지도에서 봄,
  인솔자 · 운전자는 좌석 · 탑승 · 배터리 · 한자리에 머문 시간을 보고 하산 탑승을 확인(낙오 · 조난 대비).

### 위치정보를 얻는 방법
- 이용자 핸드폰의 위치(GPS - 브라우저 Geolocation, 앱은 안드로이드 위치 서비스)를 이용자 핸드폰이 직접 읽어 우리 서버로 보냄. 이동통신사 · 다른 위치정보사업자에게서 받지 않음.
- 언제: 참가 · 동의한 뒤, 출발 3시간 전부터 하산 탑승 · 방 나가기 · 방 끝까지, 30초에 한 번. 위치를 못 잡으면 위치 없이 "폰 켜짐" · 배터리 · SOS 만(앱은 1분에 한 번).
- 받는 것: 위도 · 경도 · 정확도(m) · 배터리 % · SOS 켜짐. 출발 뒤 산행 회원은 지나온 길(10m 움직일 때마다 한 점, 메모리).

### 이용 · 제공
- 같은 방 사람들에게만 보여 줌: 회원 모두 - 별명 · 위치(마지막 하나) · SOS · 하산 탑승, 인솔자 · 운전자 - 더해서 배터리 · 탑승 · 머문 시간 · 명단에서 누른 회원의 최근 2시간 지나온 길(조난 대비). 운전자는 자기 호차 회원만(2026-10-21 - 필요한 만큼만).
- 익명 코스 통계(2026-10-21 홍TV님): 방이 끝나면(취소 빼고) 산행 회원 지나온 길을 별명 · 열쇠 · 방 코드 · 시각 없이(산행 날짜와 첫 점에서 지난 초만),
  처음 · 끝 500m 와 차를 탄 구간을 빼고 DB 표 party_track 에 둠 - 코스 구간별 실제 걸린 시간 · 많이 다니는 길 · 예상 시간 바로잡기. 개인을 알아볼 수 없게 만든 자료(익명).
- 운영자 화면 · 다른 회사 제공 · 광고 이용 없음.

### 보관 · 파기
- 위치 · 배터리 · SOS · 지나온 길: 서버 메모리에만(파일 · DB 에 쓰지 않음). 방을 나가거나 방이 끝나면 지움, 서버를 다시 켜면 지워짐.
- 익명 자취(party_track): 누구인지 알 수 없어 따로 지우는 기간 없음.
- 방 정보 · 별명 · 좌석 · 탑승 표시(좌표 없음): 서버 파일(권한 600)에 두고, 방을 나가면 그 사람 것, 방이 끝나면(인솔자가 끝냄 · 취소, 또는 하산 마감 6시간 뒤 -
  SOS 가 켜진 회원이 있으면 24시간 뒤, 늦어도 만든 지 40일) 방 전체를 지움.

### 보호조치
- 접근: 방마다 무작위 열쇠(토큰)를 가진 참가자만 그 방을 봄. 방 코드 맞히기 막기(10분 20번), 방 만들기 하루 5개, 운전자는 따로 받은 운전자 코드로만.
- 전송: HTTPS(TLS)만. 서버: AWS Lightsail 서울(ap-northeast-2), SSH 키 로그인만, 방화벽으로 22 · 80 · 443 만 엶.
- 확인자료(제16조 - 위치정보 이용 · 제공 사실): 서버 로그 party.log 에 참가(위치 제공 동의) · 나감 · 내보냄 · 출발 때 취소 · 방 끝 · SOS 의 때와 방 코드 · 방 안 번호만(좌표 · 별명 없음).
  달마다 묶고 200일(6개월 넘게) 뒤 지움.
- 관리자: 운영자 1명(홍TV님)만 서버에 접속.

### 동의 · 고지
- 참가 화면의 동의 칸(꼭 체크해야 참가): "이 방 사람들(인솔자 · 운전자 · 회원)에게 내 별명 · 위치(마지막 하나) · SOS 를, 인솔자 · 운전자에게는 배터리 · 탑승도 보여 주는 데 동의합니다.
  위치는 출발 3시간 전부터 보내고, 방을 나가거나 산행이 끝나면 지워집니다. 출발 뒤 지나온 길은 조난 대비로 인솔자 · 운전자가 최근 2시간을 볼 수 있고,
  방이 끝나면 누구인지 알 수 없게(별명 · 시각 없이, 처음 · 끝 500m 빼고) 코스 통계에 씁니다. 만 14세 이상입니다." + 개인정보처리방침 링크.
- 그만두기: 언제든 "방 나가기"(그 사람 정보 바로 지움) · 위치 권한 끄기.
- 만 14세 미만: 참가 동의에서 만 14세 이상임을 확인(제25조 - 14세 미만은 법정대리인 동의가 필요하므로 받지 않음).
- 개인정보처리방침(위치정보 포함): https://routefly.kr/routefly/privacy.html#party
- 위치정보관리책임자: 홍TV님(이름 · 연락처는 개인정보처리방침의 책임자와 같음 - 신고서에 직접).

# 산악회 방 - 단순 설계안 (2026-10-22, 홍TV님 "단순하게 설계해 봐 - 그렇지 않으면 운영에 반영하면 안 돼")

운영 반영(party.enabled)은 이 설계로 다시 만든 뒤, PC 시험을 마치고 홍TV님이 정합니다.

## 0. 원칙

1. 산행 날 인솔자가 묻는 것은 셋뿐이다: **다 탔나? · 다들 어디 있나 · 누가 위험한가.** 이 셋에 답하지 않는 것은 뺀다.
2. 회원은 **링크 → 이름 → 들어감.** 고를 것 · 적을 것이 없다.
3. 단추는 화면마다 **크게 3개 안**. 나머지는 저절로(시각 · 앱 · 지난 길).
4. 차가 여러 대면 **차마다 방 하나**(차마다 인솔자가 있음). 방 안에 호차 · 운전자 구분을 두지 않는다.
5. 덜 받으면 덜 지킨다: 좌석 · 탑승지 · 연락처 · 차량번호를 받지 않는다.

## 2. 화면

### 처음(링크 없이 열었을 때)
- `🧭 방 만들기` 한 칸뿐. (참가는 인솔자가 보낸 링크로만 - 코드 입력 칸 없음)

### 방 만들기 → 바로 "링크 보내기"
- 칸: 산행 이름 · 출발(날짜 · 시각) · 하산 마감 · 내 이름(연락처 선택).
- 만들면 바로 **💛 카톡으로 보내기 · 📋 복사** 두 단추. (QR · NFC · 문자는 뺌 - 카톡 공유 화면에 문자도 있음)

### 회원
```
설악산 공룡능선          출발까지 1시간 20분
📢 07:30까지 사당역 1번 출구          ← 공지(있을 때만)
[   🚌 탔어요   ]   ← 출발 전: 출발 탑승 / 출발 뒤: 하산 탑승
[   🆘 SOS     ]   ← 누르면 인솔자 폰이 울림 + "119 전화?"
[ ☎ 인솔자 전화 ]
(지도 - 내 위치 · 인솔자 · 일행)
```

### 인솔자
```
설악산 공룡능선 · 출발 전           [💛 링크 보내기]
✅ 탐 32 / 35 · 아직 3명: 김OO, 이OO, 박OO     ← 누르면 전화하기 쉽게 명단으로
🆘 (SOS 있으면 빨간 줄 - 누르면 지도 · 지난 2시간 길)
[ 🚌 출발 ]            ← 출발 뒤엔 [ ✅ 모두 하산 - 방 끝내기 ]
명단: 이름 · 상태(✅ 탐 / 안 탐 / 🥾 산행 중 / 🚌 하산) · 문제 표시
      이름 누르면: 지도에서 보기 · 탐/안 탐 바꾸기(폰 못 누른 분)
📢 공지 [________] [보내기]
⋯ 더 보기(접힘): 📋 명단 붙여넣기 · 🧭 함께 인솔 링크 · 방 끝내기
```

## 3. 남기는 것 · 저절로 되는 것

- **명단 붙여넣기(선택)**: 이름만 한 줄에 하나(전화번호 · 숫자는 저절로 뺌). 스마트폰이 없는 분도 명단에 올라가 인솔자가 탐/하산을 체크.
  회원이 같은 이름으로 들어오면 그 줄과 합쳐짐.
- **함께 인솔 링크**: 한 번 쓰는 인솔자 링크(사무실에서 만들고 그날 인솔자에게 · 후미대장).
- **SOS**: 화면 맨 위 빨간 줄 · 소리 · 떨림, 누르면 그 사람 지난 2시간 길.
- **저절로**: 출발 3시간 전부터 위치 · 하산 탑승하면 위치 멈춤 · 하산 마감 6시간 뒤(SOS 면 24시간) 방 끝 · 앱이면 화면 꺼도 위치 · 연결 약함 줄.

좌석 · 좌석표 · 자리 옮기기 · 예약 표시 · 호차 · 운전자 역할 · 운전자 코드 · 차량번호 · 버스 세운 자리 · 탑승지 · 최소 인원 ·
출발 때 자동 취소 · 산행 취소(→ 방 끝내기 하나) · 내보내기 · QR · NFC · 문자 · 방 코드 입력 · 배터리 % 칸 · 멈춘 시간 칸.

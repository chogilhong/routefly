# routefly 매뉴얼 3 - 🛩 내 산행을 3D 비행 영상으로 가로 영상 대본 2판 (2026-11-27 PC 화면 대조 반영)

- 꼴 · 말투 · 녹화 규칙은 README.md. 이 편은 만든 3D 영상(세로 · 가로 한 편씩)을 화면에 크게 보여 주는 자리가 많음(말 없는 화면 늘리기).
- 코드 확인(2026-11-27, course-kit.js flyStart · videoReady, app.js videoRecord): 기록 보기의 🛩 3D 영상(내 기록 · 📂 연 GPX) → 묻는 글 "3D 화면에서 N초 동안 날며 영상을 만들고 … 화면을 켜 둔 채 기다려 주세요. 영상 모양은 지금 화면 모양 그대로(폰을 세로로 들면 세로 영상)".
  N = 거리 ÷ 250m(20 ~ 60초). 시각 있는 걸은 기록은 처음 · 끝 300m 를 자름(집 · 주차한 곳), 시각 없는 코스 파일은 그대로. 영상에는 지도 · 지금 거리 · 해발 · 오른쪽 아래 고도 그래프 · 그 자리에 오면 사진(2.5초) · 출처 줄 · routefly.kr.
  위성 지도는 쓰지 않음. 끝나면 기록 보기로 돌아와 "🛩 3D 비행 영상이 준비됐습니다." 💾 저장 · 저장 안 함 - 앱은 갤러리(Movies/routefly), 인터넷 창은 내려받기. 영상은 서버로 가지 않음. 크롬이 아니면 "이 브라우저는 영상 파일을 만들 수 없습니다".
- PC 화면 대조(2026-11-27): 6 묻는 글이 "따라가기 화면으로 돌아옵니다" 였던 것은 앱 글을 "이 화면으로 돌아옵니다" 로 고침(v461). 8 연 GPX 의 묻는 창은 브라우저 창(앱에서 CANCEL · OK 영어)이라 우리 글자 창 + "시작" 단추로 고침(v461).
- 녹화: 폰 화면 녹화로 🛩 누르기 → 촬영 → 💾 저장 → 갤러리에서 재생. 내 기록은 사진 2 ~ 3장 든 짧은 기록(처음 · 끝은 영상이 자르지만 기록 보기 화면의 처음 · 끝은 흐리게).
- 제목 안: 내 등산 기록을 3D 비행 영상으로 | 사진 · 고도 그래프까지 갤러리에 저장(routefly, 무료)

## 해설(한 줄 = 한 장면, 17줄 · 965자 ≈ 2.3분 + 말 없는 화면)

```
다녀온 산행을 이렇게 3D로 날아가는 영상으로 만들 수 있습니다. 오늘은 루트플라이로 내 산행 기록을 3D 비행 영상으로 만들어 갤러리에 저장하는 방법을 보여 드리겠습니다.
준비물은 루트플라이 내 기록이나 GPX 파일 하나입니다. 인터넷 창은 크롬에서 열어 주십시오. 다른 브라우저에서는 영상 파일을 만들지 못할 수 있습니다.
내 기록에서는 기록 옆 기록 보기를 누릅니다.
다른 앱이나 시계의 GPX라면 코스 모음의 GPX 열기로 파일을 엽니다.
기록 보기 화면에서 3D 영상 단추를 누릅니다.
몇 초 동안 날며 영상을 만드는지 먼저 알려 드립니다. 영상 길이는 산행 거리에 맞춰 20초에서 60초 사이입니다.
영상 모양은 지금 화면 모양 그대로입니다. 폰을 세로로 들면 쇼츠에 맞는 세로 영상, 가로로 눕히면 가로 영상이 됩니다.
시작을 누르면 3D 화면이 열리고 출발점부터 길을 따라 날아갑니다. 다 날 때까지 화면을 켜 둔 채 기다려 주십시오.
영상에는 지금까지 온 거리와 해발이 나오고, 오른쪽 아래 고도 그래프에서 지금 자리가 함께 움직입니다.
산행 중에 사진을 남겼다면, 그 자리를 지날 때 사진이 잠깐 떠오릅니다.
지도 출처는 영상에 늘 함께 나옵니다. 지우지 말고 그대로 써 주십시오.
걸은 기록은 집이나 차를 세운 곳이 드러나지 않게 처음과 끝 300미터를 잘라서 영상을 만듭니다. 시각이 없는 코스 파일은 자르지 않습니다.
다 날면 기록 보기로 돌아오고, 영상이 준비됐다는 창이 뜹니다. 저장을 누르면 저장되고, 마음에 들지 않으면 저장 안 함을 누르면 됩니다.
앱에서는 폰 갤러리에, 인터넷 창에서는 내려받기 폴더에 저장됩니다. 영상은 서버로 보내지 않고 이 기기에서만 만듭니다.
만든 영상은 카카오톡으로 보내거나 유튜브 쇼츠, 인스타그램에 바로 올릴 수 있습니다.
가로 영상은 이렇게 나옵니다. 긴 산행 영상의 마무리로 써도 좋습니다.
다음 영상에서는 산악회 방에 회원으로 참가하는 방법을 보여 드리겠습니다. 안전한 산행 되십시오.
```

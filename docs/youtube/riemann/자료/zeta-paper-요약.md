## 여덟 걸음 (I.0 요점)

1. 영점 → 소수: G(x) ≤ x^(1/2+ε) 꼴의 한쪽 상한(소수 거듭제곱을 매끄럽게 센 G)이 성긴 긴 구간들에서만 성립해도 RH 가 나옵니다. (Part II §1 에서 증명)
2. 격자판 체비쇼프 원리: 0 이 아닌 수 N 을 여러 소수 거듭제곱이 나누면 그 곱은 |N| 이하. "나누어짐" 과 "크기" 를 견주어 소수를 위에서 누릅니다. 실제 증명에서 대상은 정수 하나가 아니라 큰 계수의 격자 사이 선형 사상입니다(Bost 기울기 부등식).
3. 내림(floor) 없는 나누어짐: n! 의 p 지수에는 내림이 있어 고전 방법은 상수밖에 못 줍니다. 복소곱(CM)에 딸린 함수의 a 차 미분은 관성 소수에서 매끄러운 하한을 가집니다(렘니스케이트 사인 예: v_p(A_a) ≥ ⌊ap/(p²−1)⌋).
4. 크기를 일차항까지: 크기를 a log a 가 아니라 a 에 일차인 항까지 알아야 합니다. 사상은 유니터리 군 사이 세타 들어올림 m 개의 사슬이고, 두 쪽 일차항이 맞아떨어집니다.
5. 분모: 사슬이 정수 격자를 정수 격자로 보내지 않을 수 있어, 소수마다 짜 맞춥니다. 오차는 갈루아 코호몰로지 길이로 누릅니다(정리 G) - 정수론 밖 수학을 가장 많이 쓰는 곳.
6. 계수(rank): 사상 하나는 목표의 가장 큰 기울기만 누르므로 사상 무리를 쓰고, 상이 고르게 퍼져 목표를 거의 다 채움을 보입니다(상대 대각합 공식).
7. 균형: 들어올림 m 개에서 오차 x/m(양 끝 한 번)과 m(걸음마다 쌓임)이 m ≈ √x 에서 맞습니다. 지수 1/2 이 여기서 나옵니다.
8. 관성 소수에서 모든 소수로: (M) 의 합은 표의 칸(잉여류)에 든 소수 거듭제곱 위이고, 평행이동 평균과 보조 소수 q, d 의 이차 지표 세 합(긴 구간에서 작음)으로 G(x) 를 얻습니다.

- 정리하면: 1 · 8 걸음은 인용한 해석적 정수론 정리로 이 글에서 증명, 7 은 변수 고르기, 2~6 이 (M) 을 이루고 (M) 은 가설로 줄였을 뿐 증명하지 않았습니다.
- 논리 뼈대: (M)(인용) + B, C(Part III) → Estimate A → 긴 구간에서 G(x) ≤ x^(1/2+ε) → RH.

## 주된 부등식 (M) 이 무엇인가 (I.5)

- 준비: 작은 ε, 규모 x. 보조 소수 q ≡ 3 (mod 8), d ≡ 7 (mod 16), q | d+1 (아주 큼). n 은 2 의 거듭제곱(x^(2+8ε) 근처), N = 4n, H 는 N 을 법으로 한 홀수 잉여류(r 와 −r 를 같게 봄, n 개), b = exp(x^ε).
- 표: 2행 × n열. 홀수 소수 거듭제곱 r = p^h 를 "행 = (1+χ_q(r))/2, 열 = [r]" 칸에 넣습니다. 칸마다 무게 w; 1행에서 밀도 δ 인 열 집합(T₂)의 칸은 무게 ≈ b, 나머지는 아주 작음.
- 소수 합 P = Σ (1 − χ_d(p^h)) log p · (a/p^h − w_칸)₊ (나누어짐 쪽), 주항 M = a(log a − 1 − γ + L'/L(1,χ_d) − ⟨log w⟩) (소수가 칸에 완전히 고르게 퍼졌을 때의 기댓값).
- (M): 평행이동 u ∈ H, 표지 t ∈ T, 반복 j = 1..m 에 걸쳐 (1/n) Σ (P − M) ≤ 𝓔, 그리고 𝓔/B ≤ x^(Cε) (x/m + xm/k + m + k/n²), B = |T| m b δ / 2.
- 말로 하면: 평행이동에 대해 평균하면 표 안의 소수는 기대보다 많지 않다(네 가지 오차까지). m = x^(1/2+O(ε)), k = x^(9/2+O(ε)).
- 글에는 q = 11, d = 1319, n = 4 의 작은 표 예가 있습니다(x = 1000 에서 P − M 의 네 평행이동 평균 −2.55). 다만 이 예는 (M) 이 증명되는 조건을 다 채우지는 않습니다.

## (M) → RH 로 가는 길

- (M) + Estimate B(규모 x 의 보조 지표) + Estimate C(훨씬 큰 규모) → Estimate A (§I.6, Part II §3~5, 예로 수치 확인)
- → 구간 [Z, Z^(3/2)] (Z 는 얼마든지 큼) 의 모든 x 에서 G(x) ≤ x^(1/2+ε)
- → 멜린 변환과 부호가 일정한 함수에 대한 란다우 정리 변형으로 임계선 오른쪽 영점 없음 = RH (§I.1, Part II §1)
- 오차 x/m 과 m 이 m ≈ √x 에서 맞아 1/2. 둘째 비용이 m² 이었다면 x^(1/3) 에서 맞아 Re s > 2/3 밖에 못 얻습니다 - 격자 비교의 정밀도가 결정적(§I.8).

## 가장 쉬운 경우: 렘니스케이트 (III.12) 줄기

- 전부 보기용입니다. Lean 개발은 렘니스케이트를 다루지 않고, RH 증명에도 쓰이지 않습니다. 대신 증명의 두 장치(관성 소수에서의 나누어짐, 주기를 통한 크기)를 가정 없이 끝까지 보여 줍니다.
- 렘니스케이트 사인의 0 에서의 미분 A_n: 정수이고 n ≡ 1 (mod 4) 가 아니면 0 (Le4).
- 관성 소수(p ≡ 3 mod 4) 모두와 모든 n 에서 v_p(A_n) ≥ ⌊np/(p²−1)⌋ (정리 Le18). 형식군의 높이 2 로그가 X − X^(p²)/p + X^(p⁴)/p² − … 꼴(부호가 번갈음, Le12 · Le13 · Le16).
- 분할 소수(p ≡ 1 mod 4)에는 이런 이득이 없음: p 는 A_p 를 나누지 않음(Le20), 5 · 13 · 17 · 29 는 어떤 A_n 도 나누지 않음.
- 크기: |A_n| ≈ n!/R^n, R = ϖ/√2 = 1.854… (정리 Le9).
- 가우스 정수의 세타 급수: T₀ = √2 ϖ/π, Θ(z)/T₀ = σ(u)²℘(u) (Le6, Le7, Le8).
- 결과로 관성 소수에 대한 체비쇼프 부등식(Le19)이 나오고, 세 결함이 드러남: (D1) 내림 오차, (D2) 소수의 절반(관성)만 나옴, (D3) 크기가 주항에서 2배 어긋남(n=101 에서 관성 소수 기여 167.7 대 log|A_n| = 306.8). 실제 증명은 이 셋을 I.4 에서 고칩니다.
- 쓴 책: Apostol(모듈러 함수 1장, 입문서), Hardy–Wright 정리 278(두 제곱수), Lucas 합동식.

## Lean 에 대한 말

- Lean 형식 증명은 모든 디리클레 L-함수에 대한 RH(GRH)를 한꺼번에 세우고, 이 글이 인용하는 명제들도 그 안에 자기 꼴로 있습니다. 제타는 자명한 지표의 경우로 같은 구성을 씁니다.
- (M) 의 완전한 증명이 형식 개발의 거의 전부이고, 그것을 사람 글로 옮기는 것이 진행 중인 일입니다.
- 이 글에서 "인용(quoted)" 표시는 Lean 개발에서 증명 없이 가져온 것, "가정(assumed)" 은 어느 절도 다루지 않고 Lean 에서 가져온 것.
- III.10 · III.11 · III.12 끝에 Lean 개발과의 대응 표가 있고, Part II 끝에 Lean 파일 목록, Part III 뒤에 수치 예를 다시 내는 스크립트 목록이 있습니다.
- Lean 이 "발표된 결과" 로 가져온 195개 항목을 III.13 에서 조사(중복 · 쓰지 않은 칸 하나 포함).

- 길이: 한 편 30 ~ 40초(2차 Vrew 기준 - 가리왕산 38초 · 명성산 30초 · 강천산 31초).

## 확인하고 쓸 것

- 용문산 은행나무: 자료에는 "높이 62m, 둘레 14m" 로 적혀 있는데, 흔히 알려진 높이와 차이가 커서 숫자는 넣지 않았습니다. 넣으려면 국가유산청(천연기념물 제30호) 자료로 먼저 확인합니다.
- 용문산 "이성계가 왕위에 오르면서" 는 자료의 "조선을 개국한 이태조가 등극하면서" 를 쉬운 말로 옮긴 것입니다. 왜 "용문" 인지는 자료에 없어 넣지 않았습니다.

- 응봉산 "묏자리" 는 자료의 "묘자리" 를 바른 말로 쓴 것입니다.
- 칠갑산 "보조 스님" 은 자료의 "보조(普照) 승려" 입니다. 철조약사여래좌상의 보물 번호(제174호)는 지금은 번호를 쓰지 않는 추세라 설명란에서 뺐습니다.

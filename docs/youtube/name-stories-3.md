# 100대 명산 이름 이야기 - 쇼츠 대본 3차(용문산 · 응봉산 · 칠갑산) (2026-11-20)

홍TV님 "3차 대본 작성해줘"(2026-11-20). 1차(계룡산 · 공작산 · 금산) `name-stories-1.md`, 2차(가리왕산 · 명성산 · 강천산) `name-stories-2.md` 와 같은 틀입니다.

- 근거: 산림청 「100대 명산 선정 이유 · 부제」(공공데이터포털 15158915, 앱의 `src/main/webapp/data/mountain-info.json`)에 적힌 내용만 씁니다. 높이는 앱의 `data/peak-elev.json` 입니다.
  자료에 없는 이야기 · 지역 이름은 넣지 않았습니다(용문산은 자료의 "경기도", 응봉산은 자료의 "울진조씨" 만). 전설 · 유래는 "~라고 합니다" 로 씁니다.
- 길이: 한 편 30 ~ 40초(2차 Vrew 기준 - 가리왕산 38초 · 명성산 30초 · 강천산 31초).
- 목소리: Vrew AI 목소리(1 · 2차와 같은 목소리), 설명란에 "해설: AI 음성". Vrew 대본에서는 "routefly" 를 "루트플라이" 로, 한자는 넣지 않음.
- 그림: 한국관광콘텐츠랩 고품질사진 공공누리 제1유형만, 표기 "ⓒ한국관광콘텐츠랩-촬영자". 화면 칸 사진은 PC 가 찾아 고르고 촬영자를 적습니다.
  쓸 사진이 없는 장면은 끝 장면의 코스 선 그리기 화면으로. 한 편 통째로 사진이 없으면 맨 아래 예비 대본(오봉산)으로 바꿉니다.
- 끝 장면: `node tools/youtube/endcard.js <산>` → target/video/end-<산>.mp4(정상에서 시작하는 내리막 코스는 뒤로 미룸).

## 확인하고 쓸 것

- 용문산 은행나무: 자료에는 "높이 62m, 둘레 14m" 로 적혀 있는데, 흔히 알려진 높이와 차이가 커서 숫자는 넣지 않았습니다. 넣으려면 국가유산청(천연기념물 제30호) 자료로 먼저 확인합니다.
- 용문산 "이성계가 왕위에 오르면서" 는 자료의 "조선을 개국한 이태조가 등극하면서" 를 쉬운 말로 옮긴 것입니다. 왜 "용문" 인지는 자료에 없어 넣지 않았습니다.
- 응봉산 자막의 "응(鷹) = 매" 는 화면 글로만 씁니다(말 칸에는 한자 없음). 자료에 한자가 없으니, 넣기 싫으시면 "응봉 = 매 봉우리" 로 바꿔도 됩니다.
- 응봉산 "묏자리" 는 자료의 "묘자리" 를 바른 말로 쓴 것입니다.
- 칠갑산 "보조 스님" 은 자료의 "보조(普照) 승려" 입니다. 철조약사여래좌상의 보물 번호(제174호)는 지금은 번호를 쓰지 않는 추세라 설명란에서 뺐습니다.
- 높이는 앱 기준(peak-elev.json)입니다. 정상석 숫자와 다르게 보이면 앱 값도 함께 점검합니다.

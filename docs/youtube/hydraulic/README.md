## 줄기(긴 영상 6부)

1. 손가락 하나로 - 파스칼의 원리, 힘 = 압력 × 넓이, 대신 거리를 내줌, 리프트 · 브레이크
2. 실린더 속 - 통 · 피스톤 · 막대 · 씰 · 와이퍼, 단동 · 복동, 들어갈 땐 빠르고 약함(넓이 셈)
3. 굴착기 - 엔진 → 펌프 → 밸브(레버) → 실린더 · 모터 → 필터 · 쿨러 → 탱크, 릴리프 밸브, Cat 320 35 MPa = 1 cm² 에 357 kg, 피스톤 하나 약 40톤
4. 역사 - 1663 파스칼 책, 1795 브라마 프레스, 1883 ~ 1977 런던 수력 회사, 물 → 기름(1920년대), 반전: 물이 덜 눌림
5. 거인들 - R 9800 · PC8000, 8만 톤 단조 프레스, 비행기 3,000 → A380 5,000 psi(= 굴착기와 거의 같은 압력)
6. 로봇 - 유압 Atlas(2013, 관절 28) → 2024 전기 Atlas(현대), 왜 전기로, EHA, 반전: 거미 다리는 유압

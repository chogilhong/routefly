## 자연 · 국립공원
- 지질(E0059697): 백악기 퇴적암 + 화강암 관입, 둘레 퇴적암이 혼펠스로 굳어 "환상구조" / 주 능선에 토르 · 판상절리 - "‘갓바위’는 화강암 토르를 조각하여 만든 불상".
- 국립공원(E0059697): "1980년 5월 도립공원으로 지정되었으며, 43년 뒤인 2023년 12월 31일 국립공원 제23호로 승격" / 야생생물 5,296종(멸종위기종 15종) / 문화유산 92점(국보 2).
- ⚠ 국립공원이 된 뒤에도 운영 /m/팔공산 코스는 모두 산림청 · 한국등산·트레킹지원센터 - 국립공원공단(knps) 코스가 아직 없음(웹 확인 - 공단 탐방로 자료에 팔공산이 들어왔는지).

- 국가유산청 「신숭겸장군유적」(시도기념물): 태조가 포위되자 "태조의 옷을 입고 변장하여 맞서다가 전사" / 태조가 순절단 · 지묘사 등을 세움, 1607 표충사.

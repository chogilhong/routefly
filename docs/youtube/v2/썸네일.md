# 산 이야기 썸네일 15장 (2026-11-21)

홍TV님 "한 김에 썸네일도 전부 만들어 줘"(2026-11-21). 쇼츠 화면 고르기는 세 장면뿐이라, 산마다 제목의 물음에 맞는 사진으로 썸네일을 따로 만듦(PC).

## 만드는 법(PC - make_v2 와 같은 도구)

- 크기 1080x1920(세로 9:16) JPG, `shorts\v2\<산>\out\thumb-<산>.jpg`
- 바탕: 아래 표의 사진(이미 영상에 쓰고 설명란에 출처를 적은 사진만). 꽉 차게 자르고 밝기 · 채도 조금(--bright 와 같게).
  CC BY-SA 사진은 자르기 · 색 바꾸기가 안 되므로("그대로" 규칙) 썸네일 바탕으로 쓰지 않음.
- 글(영상 자막과 같은 글꼴 · 테두리):
  - 위쪽 1/4: 산 이름 + 높이(노랑, 가장 크게) - 높이는 data/peak-elev.json(영상 첫 장면과 같은 값)
  - 가운데: 물음(흰색, 두 줄까지)
  - 맨 아래 작게: `100대 명산 이야기 · routefly`
- 사람 얼굴이 크게 나온 사진 · 안내판 · 글자가 많은 사진은 피함. 표의 사진이 어둡거나 세로로 자르기 나쁘면 같은 장면의 다른 사진으로(PC 고름, 바꾼 ID 를 이 표에 적기).

## 만든 것(PC 2026-11-21)

- tools\video `shorts\make_thumbs.py`(rf.ps1 thumbs [-Only "산 산"]) - ffmpeg, 맑은 고딕 굵게 · 상자 black@0.45, 바탕 eq brightness=0.04:saturation=1.15,
  위 산 이름 + 높이(#ffd54f 110px), 가운데 물음(흰 96px, 줄 끊기는 산마다), 맨 아래 40px. 금산은 "남해 금산".
- 결과 `shorts\v2\<산>\out\thumb-<산>.jpg` 15장 + `shorts\v2\_thumbs\`(모음 · _all.jpg). 콘텐츠랩 720x480 을 늘린 것은 조금 흐림(계룡산).

## 올리기(2026-11-21 홍TV님 확인)

- 2026-11-21 홍TV님이 15편 모두 올림.

- PC 의 YouTube 스튜디오에서 올림 - 콘텐츠 → Shorts → 영상 → 세부정보 → 미리보기 이미지 → 파일 업로드 → `shorts\v2\_thumbs\thumb-<산>.jpg` → 저장.
  휴대폰 앱은 영상 장면 고르기만 됨(파일 올리기 없음). 올린 그림은 채널 · 검색 목록 · 앱 목록에도 그대로 보임.
- 쇼츠 피드(위로 넘기며 보는 화면)는 썸네일 없이 영상을 바로 틀기 때문에, 영상 첫 장면에 대표 사진을 따로 넣지는 않음(make_v2 그대로).
- 사진 출처는 설명란 "사진:" 줄에 이미 있음(같은 사진).

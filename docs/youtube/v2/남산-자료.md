- 세계유산(E0002841): "2000년에 경주역사유적지구의 일부인 남산지구로서 유네스코 세계유산".

## 신라의 시작과 끝
- 나정(E0002839 · 국가유산청 사적 1975): 『삼국사기』 박혁거세가 태어난 곳 - 고허촌장 소벌공이 나정 우물 옆 숲에서 "하늘로부터 이상한 빛이 드리웠고, 그 빛 속에 흰 말 한마리가 무릎을 꿇고 울고" → 알 (줄거리로).
- 남산 신의 춤(E0002841 · 국가유산청 남산 일원): 헌강왕이 포석정에 갔을 때 남산의 신이 나타나 춤을 추었는데 왕만 보았고, 나라가 망할 것을 경고했으나 깨닫지 못했다는 전설.
- 포석정(E0060155 · 사적 1963): 『삼국사기』 "경애왕(景哀王) 4년(927) 11월에 왕이 포석정에 나가서 잔치를 하고 놀다가 … 견훤(甄萱)의 기습을 받아 왕은 죽고" / 지금은 정자 없이 전복 모양 물길(수구)만, 1915년 고칠 때 돌이 옮겨져 원형을 잃음.
- 경애왕릉(E0002841): "능 둘레는 32m이며, 신라왕릉의 규모로는 제일 작다" (견준 자료 없음 - 백과 문장).
- 삼국유사(E0002841 · 국가유산청): 남산에서 "나랏일을 의논하면 반드시 성공" 했다는 기록.
- ※ 팔공산(17번)과 이어짐: 927년 경애왕을 죽게 한 견훤이 돌아가는 길에 공산에서 왕건을 이김(팔공산-자료.md 공산전투).

## 칠불암 마애불상군(국보 2009)
- 「경주 남산 칠불암 마애불상군」(E0002854): "2009년 국보로 지정" / 바위 면 삼존불 + 앞 돌기둥 네 면의 사방불 = 7구 → 칠불암 / 본존 2.6m · 협시 2.1m, 거의 환조에 가까운 고부조 / "8세기 중엽" / 원래 석경(石經)을 벽으로 세운 석굴사원이었을 가능성.
- ⚠ E0002852 는 "1963년 보물" - 2009년 국보로 올라간 것(국가유산청 지정 20090902 국보). 대본에는 "국보".
- 신선암 마애보살반가상(보물 1963, E0002852): 칠불암 뒤 바위, 연꽃을 든 반가상.

## 용장사 - 김시습 · 금오신화
- E0002841 · 국가유산청 「용장사곡 삼층석탑」: 용장사는 "매월당 김시습이 『금오신화』를 쓰며 머물던 곳".
- 삼층석탑(보물): "자연암석을 아래층 기단으로 삼고" - "그 아래 바위산 전체가 또한 아래층 기단일 수도 있는 셈" / 높이 4.5m(E0002841) / 1922년 다시 세움.
- 석조여래좌상(보물): 원형 3층 대좌 - "삼륜대좌불" / 머리가 없음 / 『삼국유사』 대현(태현)이 미륵장륙상 둘레를 돌면 "불상도 태현을 따라 얼굴을 돌렸다고" (E0002841).
- 마애여래좌상(보물 1987): 석탑 아래 10m 암벽, 높이 1.9m.

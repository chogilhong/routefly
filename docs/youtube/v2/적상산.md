전라북도 무주의 적상산! 높이 1,030.6미터, 덕유산국립공원에 속한 산이에요.
붉은 바위 절벽이 산허리를 400미터 높이로 빙 둘러서, 마치 붉은 치마를 두른 것 같대요. 그래서 붉을 적, 치마 상, 적상산!
가을 단풍이 들면 산이 더 붉어져요. 산림청은 빨간 치마를 입은 여인 같다고 소개하고, 상산, 상성산이라고도 불렀대요.
꼭대기는 평평하고 물이 넉넉한데 산허리는 깎아지른 절벽! 그래서 하늘이 내린 요새가 됐어요.
1374년 최영 장군의 요청으로 적상산성을 쌓았대요. 거란군이 쳐들어와 이웃 고을들이 큰 화를 입었을 때도 이곳 주민들은 무사했대요.
성 둘레는 8킬로미터가 넘고, 옛 기록엔 연못이 4개, 우물이 23개나 있었대요. 1965년엔 사적이 됐어요.
1614년, 이 산성 안에 실록을 보관하는 사고를 세웠어요. 묘향산에 있던 조선왕조실록을 옮겨 와 지켰죠.
깨알 상식 하나! 정묘호란 때 지킬 사람이 없자 상훈 스님이 실록을 성 밖 석굴로 옮겨 숨겼다가, 전쟁이 끝난 뒤 다시 모셨대요.
사고를 지키려고 덕웅 스님은 승병 92명을 모아 산성을 고쳤고, 나중엔 왕명으로 지킴이 절, 호국사도 세웠대요.
실록, 선원록, 의궤까지 모두 5,515책! 1871년엔 박정양이 책을 바람과 햇볕에 쐬는 포쇄를 하러 와서 긴 가사까지 남겼대요.
1992년 양수발전소 위쪽 댐을 지으면서 사고 터가 물에 잠겨, 위쪽으로 옮겨 다시 세웠어요.

# 다음 산 10개 - PC 자료 모으기 요청 (2026-11-27)

홍TV님 "10개 진행하자"(2026-11-27). README 4장 순서 그대로: PC 가 산마다 사진 목록(tools v2\<산>\photos.tsv · extra.tsv)과 글(`<산>-자료.md`)을 올리면 → 웹 Claude 가 `<산>.md` 대본.

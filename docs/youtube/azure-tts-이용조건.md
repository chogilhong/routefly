  (https://www.microsoft.com/licensing/terms/productoffering/MicrosoftAzure/MCA)
- Microsoft 직원 답(Sairam Reddy Rajamuri · Microsoft External Staff · Moderator, 2026-10-22):
  "For monetized YouTube videos, use a paid Azure Speech TTS tier such as Standard (S0) to generate the final narration and character audio."
  "The Microsoft Product Terms expressly allow customers of the paid-tier TTS service to use audio generated by prebuilt neural voices, including for commercial purposes. This express commercial-use grant is limited to paid-tier customers."
  "The Azure pricing page identifies F0 as the Free tier and includes 0.5 million neural TTS characters per month. However, that usage allowance does not itself provide the paid-tier commercial-use grant described in the Product Terms."
  (https://learn.microsoft.com/en-us/answers/questions/6045956/can-i-use-azure-tts-prebuilt-neural-voices-free-f0)

## 정리

| | F0(무료) | S0(유료) |
|---|---|---|
| 한 달 무료 양 | 신경망 음성 50만 자 | 없음(쓴 만큼 요금) |
| 수익 영상에 쓸 권리(약관) | 약관의 상업 이용 허락에 들지 않음 | "paid tier only" - 허락됨 |
| 많이 만들 때 | 요청 수가 적어 막히기 쉬움 | 덜 막힘 |

- 지금 운영 리소스는 S0(홍TV님) - 맞는 선택.
- 아래는 공식 문장이 아니라 Q&A 의 AI 답이 권한 것(참고): F0 시절에 만든 소리는 S0 로 다시 만들어 쓰는 것이 안전("a later resource upgrade" 가 앞서 만든 소리에 거슬러 적용된다고 보지 말 것).

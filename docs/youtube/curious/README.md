## 차례(안 - 홍TV님이 정함)

1. 정상석 GPS - 우리 앱 데이터로 직접 셈한 반전(+24.8m)이 있고, 앱 이야기로 자연스럽게 이어짐.
2. 하산 무릎 - 누구나 겪는 일, 상식 바로잡기가 뚜렷함.
3. 100대 명산 - 채널 주제와 바로 이어짐, 우리 데이터 셈.
4. 메아리 - 체험(거리 재기)이 재미.
5. 산 이름 - 이야깃거리는 가장 많지만 논란(일제 지명)을 조심해서.

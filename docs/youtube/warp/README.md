# 알큐비에레 드라이브(워프 드라이브) 영상 - 계획 (2026-11-26)

긴 영상 약 15 ~ 20분(합니다체) + 쇼츠 3분(해요체), routefly 채널, 재생목록 "쉽게 보는 수학 · 과학 이야기"(안).

## 지킬 것

- 뉴스가 아니라 이야기(알큐비에레 1994). "곧 빛보다 빠른 우주선" 같은 과장 없이 - 식으로는 되지만 음의 에너지(엑조틱 물질)가 필요하고 아직 관측된 적 없음을 분명히.
- 숫자 · 연도 · 인용은 받은 자료(자료/)에서만. 나무위키는 줄기 잡기에만 쓰고 글을 옮기지 않음(CC BY-NC-SA · 누구나 고침).
- 그림은 직접 계산해 그림(거품의 공간 수축 · 팽창 = 알큐비에레 논문의 식으로).

## 순서(안)

1. 빛보다 빠르게 갈 수 있을까 - 상대성이론의 속도 한계
2. 우주선이 아니라 공간을 움직인다 - 알큐비에레의 생각(1994)
3. 워프 거품 - 앞은 수축, 뒤는 팽창(그림)
4. 걸림돌 - 음의 에너지 · 엑조틱 물질, 얼마나 필요한가
5. 그 뒤의 연구 - 필요한 에너지를 줄이려는 시도, 양의 에너지 거품(빛보다 느린)
6. 지금 어디까지 왔나 - 가능한 것과 아직 불가능한 것

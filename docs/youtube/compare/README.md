# 등산 앱 비교 영상 - 계획 (2026-11-25)

홍TV님 "우리 것도 하나 만들고 비교 영상도 하나 만들자" · "추천대로 해"(2026-11-25). 사용법(`../guide/사용법.md`) 다음에 만듦.

## 원칙(비교 광고 - routefly 는 사업)
- 숫자 · 기능은 각 앱 공식 스토어 설명 · 요금 화면 · 공식 누리집에서 확인한 것만. 따옴표로 옮기고 읽은 날짜를 적음(`앱-자료.md`). 확인 못 한 칸은 "확인 못 함".
- 영상에 확인한 날짜를 적음("2026-12 기준, 바뀔 수 있음").
- 남의 앱 화면 · 로고는 넣지 않음 - 우리가 만든 표 · 아이콘 · 글자로만. 램블러 자료 · 디자인은 쓰지 않음(규칙).
- 남을 깎아내리지 않음. "어느 게 최고" 가 아니라 "이런 분께는 이 앱" 으로 끝냄. routefly 의 없는 기능 · 모자란 점도 그대로 말함.

## 비교할 것(후보 - 자료를 본 뒤 정함)
가격(무료 · 유료 기능) · 회원 가입 · 코스 찾기 · 오프라인 지도 · GPS 따라가기 · 음성 안내 · 코스 이탈 알림 · SOS · 기록 · GPX 열기/내보내기 · 함께 산행 · 3D 미리보기 · 100대 명산 인증 · 광고.

## 순서
1. PC: 산길샘 · 트랭글 · 램블러 공식 스토어(구글 플레이 · 앱스토어) 설명 · 요금 페이지를 읽어 `앱-자료.md`(따옴표 · 날짜, 화면 캡처는 저장소에 넣지 않음).
2. 웹 Claude: 비교 표 · 대본.
3. 홍TV님 확인 → 목소리 → PC 영상.

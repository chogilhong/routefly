## 해설(한 줄 = 한 장면, 14줄)

```
안내 산악회 인솔자의 하루, 지금 많이 쓰는 방식과 루트플라이 산악회 방을 나란히 놓고 볼게요.
단톡방을 버리자는 건 아니에요. 단톡방은 그대로 쓰고, 산악회 방을 함께 쓰는 거예요.
명단. 지금은 종이나 엑셀 명단을 들고 다니죠. 산악회 방은 예약 명단을 붙여 넣으면 좌석표가 바로 그려져요.
출발 탑승. 지금은 이름을 부르고 머릿수를 세요. 산악회 방은 회원이 QR을 찍으면 좌석표 색이 바뀌어 안 탄 사람이 바로 보여요.
탑승지마다 정각 출발 안내가 회원 화면에 미리 떠요.
산행 중. 지금은 단톡방에 다들 어디쯤이세요를 남기고 기다리죠. 산악회 방은 인솔자 지도에 회원 위치가 30초마다 떠요.
연락이 안 되는 회원. 지금은 전화를 여러 번 걸어 보죠. 산악회 방은 소식이 10분, 30분, 1시간 없을 때마다 알려 주고 마지막 위치를 보여 줘요.
위급할 때. 회원이 SOS를 누르면 인솔자 폰이 울리고, 위치와 지나온 길이 바로 떠요.
공지. 단톡방 공지는 산에서 놓치기 쉬운데, 산악회 방 공지는 회원 따라가기 화면에 뜨고 소리로 읽어 줘요.
하산. 다시 머릿수를 세는 대신, 하산 탑승 숫자가 다 차면 모두 탔다고 알려 줘요.
회사는 인솔자에게 전화하는 대신 사무실 화면에서 모든 방의 탑승과 SOS를 숫자로 봐요.
개인정보도 챙겼어요. 명단에는 전화번호를 넣지 않고, 방이 끝나면 위치를 지워요. 회사 사무실에는 이름과 위치 없이 숫자만 남아요.
솔직히 모자란 점도 있어요. 회원 폰이 켜져 있어야 위치가 가고, 산속에서 신호가 약하면 위치가 늦게 올라와요. 아이폰은 앱 없이 인터넷 창으로 써요.
정리하면, 단톡방은 연락용으로 그대로 두고, 탑승과 위치, SOS는 산악회 방에 맡겨 보세요. 인솔자님 걱정이 훨씬 줄어들 거예요.
```

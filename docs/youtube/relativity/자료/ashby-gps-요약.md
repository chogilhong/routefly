# Ashby(2003) GPS 와 상대성이론 · 위키백과 Error analysis for the GPS 요약 (자료 9)

## Ashby(2003)

- 제목: Relativity in the Global Positioning System
- 지은이: Neil Ashby
- 실린 곳: Living Reviews in Relativity, 2003년 12월, doi 10.12942/lrr-2003-1
- 주소: https://link.springer.com/article/10.12942/lrr-2003-1 (PDF https://link.springer.com/content/pdf/10.12942/lrr-2003-1.pdf, 받은 날 2026-11-27)
- README 의 주소 · 제목 · 지은이 · 연도가 모두 맞음(웹 Claude 기억 확인).
- 원문 · PDF 는 저장소에 넣지 않음. 요점만.

- GPS 에는 1차 · 2차 도플러, 중력 진동수 이동, 지구 자전의 사냐크 효과 같은 상대론 효과가 있고, 바로 다루지 않으면 항법 · 시간 전달에 큰 오차가 생긴다.
- 좋은 세슘 시계는 하루 두면 약 5 × 10⁻¹⁴, 약 4 ns 안 - 상대론 효과는 이보다 훨씬 큼.
- 위성 시계의 일정한 진동수 보정(식 35): +2.5046 × 10⁻¹⁰ − 6.9693 × 10⁻¹⁰ = −4.4647 × 10⁻¹⁰. 음수 = 궤도의 시계가 너무 빨리 감(주로 중력 청색편이). 그래서 위성 시계를 10.23 MHz 보다 조금 낮게 맞춰 띄움.
  (참고 셈: 4.4647 × 10⁻¹⁰ × 86,400 s ≈ 38.6 μs/일 - PC 가 곱한 값)
- 낮은 궤도(우주왕복선)는 속도 효과가, GPS 는 중력 효과가 큼, 둘이 상쇄되는 궤도 반지름 약 9,545 km. 갈릴레오는 궤도 반지름 약 30,000 km 예정.
- 첫 위성 때 공장 진동수 보정에 지구 원심 퍼텐셜이 빠진 오류가 있었고, 알린 뒤 규격을 바꾸기까지 8년이 걸렸다는 이야기.
- ※ GPS 위성 고도(약 2만 km) 숫자는 받은 글에서 찾지 못함.

## 위키백과 Error analysis for the Global Positioning System

- 주소: https://en.wikipedia.org/wiki/Error_analysis_for_the_Global_Positioning_System
- 속도 효과: 궤도 속도 약 4 km/s(지구 중심 기준 3,874 m/s) → 위성 시계가 하루 약 −7.2 μs.
- 중력 효과: 위성 고도의 시계가 약 5 × 10⁻¹⁰ 빨라 하루 약 +45.8 μs.
- 합: 45,850 − 7,210 = 38,640 ns → 하루 약 +38.6 μs, 4.465 × 10⁻¹⁰.
- 보정하지 않으면 하루 약 11.4 km 씩 오차가 쌓임.

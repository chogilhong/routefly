# 산 페이지 대표 사진 · 공유 그림 (2026-11-21)

홍TV님 "고급지게" 1번(맨 위 대표 사진) · 5번(공유 그림에 사진 + 이름 + 높이). 코드는 끝났고, 사진 파일만 PC 가 넣으면 보입니다.

## 어디에 쓰나

- 산 페이지(/m/<산> · /en/m/<slug>) 설명 줄 바로 아래 큰 사진 + 오른쪽 아래 작은 출처 줄(`MountainServlet.heroBlock`).
- 공유 그림(/og/m/<산>.png - 카톡 · 밴드에 링크를 붙이면 뜨는 그림): 사진을 꽉 차게 자르고 아래쪽을 어둡게, 흰 글로 산 이름 · 높이, 오른쪽 아래 출처(`OgServlet.photoPng`).
- 사진이 없는 산은 지금 그대로(사진 칸 없음 · 예전 공유 그림).

## 넣는 법(PC)

1. 바탕 사진은 `docs/youtube/v2/썸네일.md` 표의 사진에서 고릅니다(이미 영상에 쓰고 출처를 적은 사진). 가로 사진이 좋습니다(세로 사진은 가운데만 보임).
2. 쓸 수 있는 사진: 공공누리 제1유형(`kogl1`) · CC0(`cc0`)만. 페이지와 공유 그림이 사진을 자르므로 CC BY-SA(그대로만)는 넣지 않습니다(코드가 막음). "AI 사용 금지" 사진도 넣지 않습니다.
3. 가로 1600px 안팎 jpg(품질 80 · 200KB 안팎)로 줄여 `src/main/webapp/img/hero/<영문 소문자 · 숫자 · ->.jpg` 로 저장(예: `dutasan.jpg`). 색은 바꾸지 않습니다.
4. `src/main/webapp/data/hero.json` 의 heroes 에 한 줄:
   ```
   "두타산": {"src": "img/hero/dutasan.jpg", "w": 1600, "h": 1067, "credit": "ⓒ한국관광콘텐츠랩 - 손명권 (공공누리 제1유형)", "license": "kogl1", "alt": "두타산 능선"}
   ```
   - 산 이름은 mountains100.json 의 id(shorts.json 과 같은 이름).
   - w · h 는 줄인 뒤 실제 크기. credit 은 올리기 파일의 출처 글을 그대로.
5. 테스트(MountainHeroTest 가 규칙과 파일이 있는지 봄) → 커밋 · push. 공유 그림은 서버가 하루 담아 두므로 배포 뒤 다시 띄워야 새 그림.

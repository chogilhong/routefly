# 원스토어 등록 (2026-10-20 홍TV님 - Play 스토어보다 먼저)

원스토어 개발자센터(https://dev.onestore.co.kr)에서 합니다. 개발자 등록은 무료입니다. 개인도 판매자로 가입할 수 있습니다.
화면 · 요구 항목은 바뀔 수 있으니 개발자센터에 나오는 안내를 따르고, 이 문서는 우리 앱에 맞춘 답 · 글을 모아 둔 것입니다.
계정 · 본인인증 · 비밀번호 · 서명 키 비밀번호는 홍TV님이 직접(Claude 는 다루지 않음).

## 1. 순서

1. 개발자센터 회원가입(개인) - 본인인증. 무료 앱이라 정산 계좌는 지금 넣지 않아도 되면 건너뜀.
2. 앱 파일 만들기(PC - Android Studio, `app/README.md` "스토어용") - 아래 2번.
3. APPS → 새 앱 등록: 앱 이름 · 패키지 `kr.routefly.app` · 분류 · 소개 글 · 아이콘 · 화면 사진 · 개인정보처리방침 주소(아래 3번).
4. 앱 파일 올리기 → 심사 요청. 심사 결과는 메일 · 개발자센터로 옴.
5. 심사 통과 → 판매(공개) 시작. 원스토어 앱 주소가 나오면 웹 Claude 에게 알려 주기(산악회 방 "앱 받기" 링크).

## 2. 앱 파일 · 서명 키

- 버전: `app/android/app/build.gradle` 의 versionCode 1 · versionName "1.0"(처음). 올릴 때마다 versionCode 를 1씩 올림.
- 서명 키(.jks): 처음 한 번 만들고 평생 같은 키로 올려야 업데이트가 됩니다. 잃어버리면 앱을 고칠 수 없으니 저장소 밖 두 곳에 보관(저장소에 넣지 않음).
  Android Studio → Build → Generate Signed App Bundle or APK → Create new… (비밀번호 · 이름은 홍TV님이 입력).
- 원스토어는 APK 와 AAB 둘 다 받습니다. 권장: 우리 키로 서명한 APK.
  - 이유: 산악회 방 "앱 링크"(카톡 링크 → 앱)가 서버 `app.sha256` 에 적힌 서명 지문으로 확인됩니다. 우리 키로 서명하면 지문이 하나로 정해집니다.
  - AAB 로 올리면서 "원스토어 앱 서명"을 고르면 원스토어 키로 다시 서명되므로, 그 지문을 개발자센터에서 찾아 `app.sha256` 에 더해야 합니다.
- 새 서명 키를 만들면 그 SHA-256 지문을 PC Claude 가 읽어(keytool -list - 지문 줄만) 홍TV님이 서버 `app.sha256` 에 쉼표로 더합니다(시험판 debug 지문과 함께).
- 같은 패키지를 Play 스토어에도 올리면, 원스토어로 깐 앱은 Play 스토어가 업데이트하지 않습니다(스토어마다 따로 받음). 문제는 아님.

### 짧은 소개(한 줄)

100대 명산 · 등산 코스를 3D 로 미리 보고, GPS 로 따라 걷고, 안내 산악회는 인솔자가 회원 위치 · SOS 를 봅니다.

```
routefly 는 등산 · 걷기 · 자전거 코스를 3D 지형 위로 날아가며 미리 보고, 산에서는 핸드폰 GPS 로 따라 걷는 앱입니다.

■ 코스 미리 보기
- 100대 명산 · 국립공원 탐방로 · 둘레길 · 자전거길을 3D 지형으로
- 거리 · 오르막 · 예상 시간, 들머리 주차장, 날씨 · 미세먼지 · 산행 안전 정보

■ 따라가기(산행 중)
- GPS 로 내 위치와 코스를 함께, 갈림길 · 코스 이탈 음성 안내
- 화면을 꺼도 기록 · 안내가 이어짐(알림창에 "따라가는 중")

- SOS: 내 위치를 문자로 보내기, 119
- 산행 기록 · 사진 · 메모는 이 핸드폰에만 저장, GPX 로 내보내기

■ 산악회 방(안내 산악회 · 인솔자)
- 인솔자가 방을 만들어 카톡 · 문자 · QR 로 회원을 부름
- 좌석표 · 탑승지 · 출발 탑승 확인, 차량 여러 대(호차) · 차량번호

- 하산 탑승 확인, 방이 끝나면 위치를 모두 지움

■ 개인정보
- 회원 가입 · 로그인이 없습니다. 위치는 산악회 방에 참가 · 동의한 동안만 같은 방 사람들에게 보입니다.
- 자세한 내용: https://routefly.kr/routefly/privacy.html
```

## 4. 등록 뒤

- 원스토어 앱 주소를 웹 Claude 에게 → 산악회 방 "앱으로 열기" 안내에 "원스토어에서 받기" 링크.
- AAB + 원스토어 앱 서명을 골랐다면 그 서명 지문을 서버 `app.sha256` 에 더하기(홍TV님).
- 업데이트: 화면 · 기능 대부분은 서버(routefly.kr)에서 바로 바뀌므로 앱을 다시 올릴 일은 드뭅니다. 앱 안 코드(app/ - 앱 링크 · 백그라운드 위치 등)가 바뀔 때만 versionCode 를 올려 다시 올림.

## 판정(2026-11-17 홍TV님 확인 + 법 원문 docs/dronefly/law/, 시행 2026. 11. 13.)

법 원문에서 판정에 쓰는 곳:
- 법 제127조 ③ · 시행규칙 제308조 ⑤ ⑥: 무게와 상관없이 승인 - 150m 이상(사람 · 건물 밀집 지역은 반경 150m 안 가장 높은 장애물 위 150m), 관제권, 비행금지구역.
- 시행규칙 제308조 ① 4호: 최대이륙중량 25kg 이하 무인동력비행장치는 법 제127조 ②(비행제한공역 비행승인) 대상에서 빠짐.
- 시행규칙 제310조 ① 3호 나목: 25kg 이하는 관제권 · 비행금지구역이 아닌 곳에서 150m 미만이면 관제공역 · 통제공역 · 주의공역에서도 날 수 있음.
- 시행규칙 제310조 ① 6호: 야간(일몰 후 ~ 일출 전) 비행 금지 - 법 제124조 허가(특별비행)를 받은 경우만. ④ 눈으로 볼 수 있는 범위에서.
- 열린 질문(홍TV님께): 원문대로면 비행제한구역(R)도 25kg 이하 · 150m 미만은 승인 대상이 아님(310조 ① 3호 나목은 관제권 · 비행금지구역만 뺌). 화면은 지금 R 을 "승인 필요"로 둠 - 실무(예: R75 수도방위사령부)에 맞춰 정해 주셔야 함.


| 자리 | 판정 | 뜻 |
|---|---|---|
| 비행금지구역(P) | 금지(빨강) | 승인 없이 비행 불가 |
| 비행제한구역(R) | 승인 필요(주황) | |
| 관제권(CTR · CTLZ · 공항 이름) | 승인 필요(주황) | 무게 · 고도 상관없음 |
| 접근관제구역(이름에 TCA) | 그 밖과 같음 | 25kg 이하 · 150m 미만 · 낮이면 승인 없이(홍TV님 화면) |
| 군작전구역(MOA · CATA) | 확인(노랑) | 다른 공역과 겹치지 않으면 25kg 이하 · 150m 미만 · 낮은 승인 없이, 아래 높이가 SFC 면 관할 부대 확인 |
| UA 공역 | 허용(초록) | 낮(일출 ~ 일몰)에 표시된 높이까지 승인 없이 |
| 그 밖 | 허용(초록) | 25kg 이하 · 150m 아래 · 낮 · 눈으로 보이는 곳이면 승인 없이 \| 국토부 안내 |

- 여러 공역이 겹치면 가장 엄한 것으로.
- 늘 함께: 150m 이상 · 25kg 초과 → 어디서나 승인 필요, 야간(일몰 후 ~ 일출 전) → 특별비행승인.
- 항공촬영(카메라로 찍음)은 판정에 넣음(홍TV님 "판정(필수 이행 조건)에 포함"): 국방부 항공촬영 허가가 따로 필요 - 판정 줄에 "+ 촬영 허가".
- 신청: 비행승인을 대신 보내는 공개 API 없음 → 신청할 값 정리 · 복사 + 드론원스톱(https://drone.onestop.go.kr) 열기.

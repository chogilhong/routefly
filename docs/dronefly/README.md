## 자료

- 공역: 브이월드 2D 데이터 API 항공 레이어(국토교통부). `web.DroneProbe` 가 받아 `src/test/resources/drone/` 에 두고,
  `web.DroneAirspace` 가 칸을 줄여 `src/main/webapp/data/drone-airspace.json` 을 만듭니다(DroneAirspaceTest 가 둘이 같은지 봄).
  - lt_c_aisprhc 비행금지구역 15 · lt_c_aisresc 비행제한구역 84 · lt_c_aisctrc 관제권 레이어 53(CTR · CTLZ · TCA AREA 섞임) · lt_c_aismoac 군작전구역 75 · lt_c_aisuac 초경량비행장치공역(UA) 48 (2026-11-17 받음)
  - lt_c_aistemp · lt_c_aisdronezone 은 INVALID_RANGE(그런 레이어 없음) - 임시 비행금지는 아직 없음.
  - 키: map.vworld.key + domain=routefly.kr(도메인을 빼면 INCORRECT_KEY).
- 위치는 폰 안에서만 비교합니다(공역 파일을 받아 폰이 셈 - 서버로 보내지 않음). 장소 찾기는 /api/place(이름만).

## 판정(2026-11-17 홍TV님 확인 - 법 원문 제308조 · 제310조는 PC 가 받는 중)

| 자리 | 판정 | 뜻 |
|---|---|---|
| 비행금지구역(P) | 금지(빨강) | 승인 없이 비행 불가 |
| 비행제한구역(R) | 승인 필요(주황) | |
| 관제권(CTR · CTLZ · 공항 이름) | 승인 필요(주황) | 무게 · 고도 상관없음 |
| 접근관제구역(이름에 TCA) | 그 밖과 같음 | 25kg 이하 · 150m 미만 · 낮이면 승인 없이(홍TV님 화면) |
| 군작전구역(MOA · CATA) | 확인(노랑) | 다른 공역과 겹치지 않으면 25kg 이하 · 150m 미만 · 낮은 승인 없이, 아래 높이가 SFC 면 관할 부대 확인 |
| UA 공역 | 허용(초록) | 낮(일출 ~ 일몰)에 표시된 높이까지 승인 없이 |
| 그 밖 | 허용(초록) | 25kg 이하 · 150m 아래 · 낮 · 눈으로 보이는 곳이면 승인 없이 \| 국토부 안내 |

- 여러 공역이 겹치면 가장 엄한 것으로.
- 늘 함께: 150m 이상 · 25kg 초과 → 어디서나 승인 필요, 야간(일몰 후 ~ 일출 전) → 특별비행승인.
- 항공촬영(카메라로 찍음)은 판정에 넣음(홍TV님 "판정(필수 이행 조건)에 포함"): 국방부 항공촬영 허가가 따로 필요 - 판정 줄에 "+ 촬영 허가".
- 신청: 비행승인을 대신 보내는 공개 API 없음 → 신청할 값 정리 · 복사 + 드론원스톱(https://drone.onestop.go.kr) 열기.

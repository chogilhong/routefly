## 판정(2026-11-17 홍TV님 확인 + 법 원문 docs/dronefly/law/, 시행 2026. 11. 13.)

법 원문에서 판정에 쓰는 곳:
- 법 제127조 ③ · 시행규칙 제308조 ⑤ ⑥: 무게와 상관없이 승인 - 150m 이상(사람 · 건물 밀집 지역은 반경 150m 안 가장 높은 장애물 위 150m), 관제권, 비행금지구역.
- 시행규칙 제308조 ① 4호: 최대이륙중량 25kg 이하 무인동력비행장치는 법 제127조 ②(비행제한공역 비행승인) 대상에서 빠짐.
- 시행규칙 제310조 ① 3호 나목: 25kg 이하는 관제권 · 비행금지구역이 아닌 곳에서 150m 미만이면 관제공역 · 통제공역 · 주의공역에서도 날 수 있음.
- 시행규칙 제310조 ① 6호: 야간(일몰 후 ~ 일출 전) 비행 금지 - 법 제124조 허가(특별비행)를 받은 경우만. ④ 눈으로 볼 수 있는 범위에서.
- 비행제한구역(R): 원문대로면 25kg 이하 · 150m 미만은 승인 대상이 아니지만(310조 ① 3호 나목), 실무(R75 등)대로 "승인 필요"로 둠(2026-11-17 홍TV님 1안). 판정 아래 "단, 일부 비행제한구역은 25kg 이하 · 150m 미만 기체에 한해 예외 … 드론원스톱에서 세부 고시 확인" 을 덧붙임.


| 자리 | 판정 | 뜻 |
|---|---|---|
| 비행금지구역(P) | 금지(빨강) | 승인 없이 비행 불가 |
| 비행제한구역(R) | 승인 필요(주황) | |
| 관제권(CTR · CTLZ · 공항 이름) | 승인 필요(주황) | 무게 · 고도 상관없음 |
| 접근관제구역(이름에 TCA) | 그 밖과 같음 | 25kg 이하 · 150m 미만 · 낮이면 승인 없이(홍TV님 화면) |
| 군작전구역(MOA · CATA) | 확인(노랑) | 다른 공역과 겹치지 않으면 25kg 이하 · 150m 미만 · 낮은 승인 없이, 아래 높이가 SFC 면 관할 부대 확인 |
| UA 공역 | 허용(초록) | 낮(일출 ~ 일몰)에 표시된 높이까지 승인 없이 |
| 그 밖 | 허용(초록) | 25kg 이하 · 150m 아래 · 낮 · 눈으로 보이는 곳이면 승인 없이 \| 국토부 안내 |

- 여러 공역이 겹치면 가장 엄한 것으로.
- 늘 함께: 150m 이상 · 25kg 초과 → 어디서나 승인 필요, 야간(일몰 후 ~ 일출 전) → 특별비행승인.
- 항공촬영(카메라로 찍음)은 판정에 넣음(홍TV님 "판정(필수 이행 조건)에 포함"): 항공촬영 사전 신청(2022. 12. 1. 부터 허가 → 사전 신청, 지역책임부대가 촬영금지시설 유무 안내 - 드론원스톱 항공촬영 신청 안내)이 따로 필요 - 판정 줄에 "+ 촬영 사전 신청". P518 · R73 · R75 는 신청 전 드론원스톱 공지사항 확인 줄.
- 신청: 비행승인을 대신 보내는 공개 API 없음 → 신청할 값 정리 · 복사 + 드론원스톱(https://drone.onestop.go.kr) 열기.

## 비행 날씨 · 날 수 있는 시간 · 점검표 · 기록장 (2026-11-18 홍TV님 "1~8 전부")

- 비행 날씨: /api/weather(기상청 단기예보 - 산 페이지와 같은 WeatherServlet)를 그 자리가 든 0.05° 고정 칸(약 5km, `DF.wxCell`)의 가운데 좌표로 묻고 판정은 폰이(`DF.flyWx`).
  비행 계획 날 · 시각(시작 ~ 끝 시) 안의 시간 칸에서 가장 센 바람 · 비 · 눈 · 가장 낮은 기온. 계획 날이 단기예보 밖이면(기본 날짜는 신청 기간 뒤라 흔함) 오늘 남은 때를 대신 보임.
  ✕ 비 · 눈(강수형태 PTY > 0) 또는 풍속 ≥ 기체 최대 풍속, △ 풍속 > 최대 풍속의 70%, ○ 그 아래. 기체 최대 풍속은 사용자가 설명서 값을 넣음(이 폰에만 df-wind) - 넣기 전에는 비 · 눈만 ✕ 이고 숫자만 보임.
  근거: 제작자가 정한 풍속 기준을 넘지 않게(시행규칙 제310조 ⑤ 3호 - 레저사업 조종자 조항이지만 같은 원칙). 70% 는 돌풍 여유로 routefly 가 정한 값(화면에 그렇게 적음) - 홍TV님이 바꾸라고 하면 바꿈.
  기상청 풍속은 지상 10m 평균이라 돌풍 · 높은 곳은 더 셈(화면에 적음). 시정(안개)은 단기예보에 없어 판정하지 않음(제310조 ① 4호는 점검표 · 판정 줄로).
- 날 수 있는 시간: 계획 날의 일출 ~ 일몰(폰이 계산 - RF.sunrise · RF.sunset, 산 페이지와 같음). 계획 시각이 그 밖이면 "야간에 걸림 - 특별비행승인"(제310조 ① 6호).
- 비행 전 점검: `DF.CHECKS` 11줄(공역 신청 · 날씨 · 낮 · 신고 · 증명 · 배터리 · 프로펠러 · 펌웨어 · GPS · 귀환 높이 · 눈으로 보이는 곳 · 음주 · 보험). 고른 것은 그날만(df-check).
- 비행 기록장: 날짜 · 비행 시간(분) · 장소 · 기체 · 메모를 이 폰에만(df-log, 500개까지), CSV(BOM - 엑셀 한글)로 저장. 서버로 보내지 않음.

이 문서가 관리적 조치(관리책임자 · 취급 지침 · 취급대장 · 자체 점검)의 내부 문서입니다. 바뀌면 고친 날과 내용을 맨 아래 "고친 기록"에 적습니다.
주소 · 전화 · 사업자번호 같은 사업자 정보는 이 저장소에 적지 않습니다(운영 설정 biz.* 와 공문 사본 E:\GH\routefly\lbs\ 에만).

## 3. 취급 지침

1. 위치는 이용자가 참가할 때 동의(체크 칸)한 경우에만 받습니다. 동의 없이 받는 길을 만들지 않습니다(PartyServlet "위치 제공에 동의해야").
2. 위치는 그 방 인솔자 · 운전자에게만 보입니다. 회원끼리는 보지 않습니다(Party.view, PartyTest).
3. 운영자도 위치를 보는 화면을 만들지 않습니다. 장애 조사로 서버 메모리 · 파일을 볼 때도 위치를 따로 옮겨 적지 않습니다.
4. 로그 · 오류 글 · 통계에 좌표 · 이름을 넣지 않습니다(확인자료는 방 코드 · 번호만).
5. 위치를 다루는 코드를 고치면 개인정보처리방침 · 위치기반서비스 이용약관 · 이 문서를 함께 고치고, PartyTest · PartyRosterTest · PrivacyPolicyTest 를 돌립니다.
6. 이용자의 열람 · 고지 · 정정 요구(법 제24조)는 메일 · 의견 보내기로 받아 지체 없이 답합니다. 받은 날 · 처리한 날을 아래 취급대장에 적습니다.

## 4. 기술적 조치 (지금 되어 있는 것 - docs/deploy-lightsail.md)

- 접근 인증: 운영 서버는 SSH 열쇠(.pem)로만 들어감. 열쇠 파일 · 비밀번호는 저장소에 없음.
- 방화벽: Lightsail 방화벽 SSH(22) · HTTP(80) · HTTPS(443)만, 8080 · 3306 은 닫음.
- 전송 암호화: HTTPS(Let's Encrypt), HSTS. 위치는 https 로만 오감.
- 접근 기록: nginx · 톰캣 접속 기록(? 뒤 없이), 확인자료 200일.
- 남용 막기: SecurityFilter(요청 수 제한 · 보안 헤더 · CSP), PartyServlet(참가 · 방 만들기 수 제한, JSON 만).
- 보안 프로그램: 서버 운영체제 보안 업데이트(Ubuntu unattended-upgrades) - 켜져 있는지 아래 자체 점검 때 확인.

## 6. 정기 자체 점검 (분기마다 한 번: 1 · 4 · 7 · 10월)

- [ ] party.log · party-*.log.gz 가 남고 200일 지난 것이 지워지는지
- [ ] party.json 권한이 600 인지(`ls -l`)
- [ ] Lightsail 방화벽 포트가 22 · 80 · 443 만인지
- [ ] HTTPS 인증서 갱신(certbot.timer)이 도는지
- [ ] Ubuntu 보안 업데이트가 켜져 있는지
- [ ] 개인정보처리방침 · 위치기반서비스 이용약관이 코드와 맞는지(PrivacyPolicyTest 통과)
